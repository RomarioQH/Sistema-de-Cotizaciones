Every `.py` module is a separate Lambda handler. Upload the same `dist/lambda-code.zip` to the function and set its handler as listed in `README.md`. The deployed function must use Python 3.13 / x86_64 and attach the matching ODBC layer for any handler that imports SQL modules. Cognito operations use boto3, available in the Lambda runtime; pin/package boto3 only if your runtime packaging standard requires it.
